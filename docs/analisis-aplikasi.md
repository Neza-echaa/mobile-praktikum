# Analisis Aplikasi myXL

## 1. Aplikasi yang Diamati

myXL merupakan aplikasi layanan telekomunikasi yang menyediakan berbagai layanan bagi pengguna atau pelanggan XL, seperti pengecekan kuota, pembelian paket, dan pengelolaan nomor secara mandiri.

## 2. Pengguna

Pengguna utama aplikasi myXL adalah pelanggan XL. Aplikasi ini membantu pengguna mengelola nomor XL, seperti mengecek pulsa, membeli paket internet, dan melihat penggunaan kuota tanpa harus datang ke konter.

## 3. Fitur Utama

### 1. Cek Kuota dan Pulsa
Pengguna dapat melihat sisa kuota internet dan jumlah pulsa yang dimiliki secara langsung.

### 2. Beli Paket Data dan Pulsa
Pengguna dapat membeli paket internet atau melakukan isi ulang pulsa melalui aplikasi tanpa perlu datang ke konter.

### 3. Top Up e-Wallet dan Listrik
Pengguna dapat melakukan pengisian saldo e-wallet serta pembayaran atau pembelian kebutuhan listrik melalui aplikasi.

## 4. Usulan Perbaikan

Pengguna harus melewati beberapa langkah untuk menemukan paket tertentu. Usulan perbaikannya adalah menyediakan fitur pencarian atau filter paket yang lebih jelas berdasarkan kebutuhan, misalnya paket harian, paket bulanan, atau paket murah. Hal ini dapat mempercepat pengguna menemukan paket yang sesuai.
